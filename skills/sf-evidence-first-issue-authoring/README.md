# sf-evidence-first-issue-authoring

Investigates a repository and drafts or audits evidence-grounded engineering issues. Unverified work is routed to an investigation or product-decision issue instead of an invented implementation-ready ticket.

## Install

With the Agent Skills installer:

```bash
npx skills add toeydevelopment/firstmate --skill sf-evidence-first-issue-authoring
```

As a Claude Code plugin:

```text
/plugin marketplace add toeydevelopment/firstmate
/plugin install sf-evidence-first-issue-authoring@toeydevelopment-firstmate
```

The skill itself is in [SKILL.md](SKILL.md).
